# The Art Factory — static portfolio

Open `index.html` directly in a browser or serve this folder with any static web host. The site uses plain HTML, CSS and vanilla JavaScript.

## Before publishing

- Add the studio's WhatsApp phone number to the enquiry links. They currently open WhatsApp's recipient picker with the enquiry text prefilled because no business number was supplied.
- Replace the generic Instagram links and blank-recipient email links in `index.html` with the studio's real profile and email address.
- Replace the sample testimonial with an approved customer review.
- The included portfolio has five unique portrait images supplied with the brief. Add more actual artworks as files under `assets/` and add corresponding `.artwork-card` buttons in `index.html` to build it out to the requested gallery of about 20 pieces. The landscape example was excluded from the portrait gallery.

The contact form validates name, email and message in the browser, then prepares the enquiry in WhatsApp. It does not claim to submit or store form data.
